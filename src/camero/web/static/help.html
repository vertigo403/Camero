Camero Help
How Camero works and how to use it effectively.
What Camero is
Camero is a local catalog manager for recorded webcam stream sessions. It scans your video folders, extracts metadata (streamer, site, date/time, codecs, duration, etc.), and lets you browse, tag, preview, and organize recordings from a web-based interface.
Camero runs on your own computer and opens a browser UI. By default it listens at http://127.0.0.1:6969, and you can change the backend IP/host and port in Settings, including binding to an external IP when needed. No cloud services are required.
Portable app & removable drives
Camero is designed to be portable: your catalog’s database and generated metadata live inside your catalog folder (under .camero/). This means the catalog “travels with” the recordings.
Camero also works well with removable drives. On Windows, it can keep tracking the active catalog even if the same drive appears with a different letter, thanks to a stable volume identifier.
Key concepts
  • Catalog root: the main folder that contains your recordings. Camero stores catalog metadata inside it under .camero/.
  • Catalog folders: optional additional folders to scan (each can have its own filename pattern). Useful for split libraries or multiple download locations.
  • Recordings: individual video files. You can filter, tag, move/copy, remux/transcode, and open them in an external player.
  • Streamers: people/channels detected from filenames (or set manually). Streamers can have a site and an avatar.
  • Sites: platforms (e.g., the streaming site). Used for filtering and organization.
  • Tags: custom labels you assign to recordings for quick filtering and organization.
First run checklist (inside the app)
  • Open Settings (⚙) and set your Catalog root.
  • (Optional) Add one or more Catalog folders if you keep recordings in multiple locations.
  • Go to Recordings and click Scan catalog to populate the database.
  • Go to Recordings to browse and start tagging/organizing.
How scanning and filename parsing works
Scanning reads files on disk and extracts metadata. A lot of the initial metadata (Streamer, Site, Date, Time) is parsed from filenames using a regular expression. The default pattern expects something like:
<streamer>_<site>_<YYYYMMDD>_<time>.<ext>
If your naming scheme is different, adjust the filename regex in Settings. Camero accepts named groups such as streamer, site, date, time.
If you need to update already-scanned entries after changing patterns, use Rescan metadata on selected recordings.
Recordings page
Browsing
  • Sort by date, title, streamer, duration, size, or resolution.
  • Use Filters (funnel icon) for advanced filtering (size, duration, resolution, codecs).
  • Use pagination controls to navigate large libraries.
Card actions
  • 📁 Open containing folder.
  • ▶️ Open in your default external player.
  • 🏷️ Assign tags.
  • Create preview: generates an animated thumbnail preview for hover playback.
You can also select multiple recordings (checkbox overlay) and use bulk actions like delete, assign tags/sites, move/copy, rescan metadata, or start a transcode.
Recording details (player modal)
  • Playback happens inside the browser using an embedded player.
  • Use ←/→ to skip -5s / +5s (when the modal is open).
  • Edit metadata: set Streamer, Site, or Date if parsing didn’t detect it correctly.
  • Set thumbnails:
    • Set current frame as streamer avatar
    • Set current frame as recording thumbnail
  • Tags: add/remove tags directly from the modal.
Animated previews
Animated previews are short MP4 clips used for hover playback on recording cards. Camero builds previews from multiple 1-second fragments sampled across the video.
If your catalog is large, generating previews can be time-consuming. You can create them per-recording, run Generate animated previews from the Recordings toolbar, and optionally enable Generate animated previews after scan in Settings.
You can configure how many fragments are used (5/10/15/20, default 10) in Settings.
Move & Copy
Bulk Move and Copy let you send recordings to any folder on this computer. A dialog lets you type a destination path or pick one with a native folder chooser.
  • Move to a folder inside the catalog keeps the recording in the catalog (it is re-located).
  • Move to a folder outside the catalog removes the recording from the catalog (it is treated as an export).
  • Copy copies files to the destination and keeps the originals in the catalog.
  • Preserve folder structure recreates the recording's folder structure inside the destination folder.
Remux vs Transcode
Remux (Make playable)
Some containers (like .mkv, .avi, .ts) are often not playable directly in browsers. Camero can remux the file so the browser can play it.
Remuxing changes the container but keeps audio/video streams as-is (no re-encoding).
Transcode
Transcoding (re-encoding) is used when you need a different codec/format or want standardized outputs. It runs as a background job and shows progress.
While a transcode job is running, Camero can show a floating progress widget. You can restore the full dialog from it.
Streamers
The Streamers view lists detected streamers and lets you:
  • Filter by site, search by name, and use A–Z shortcuts.
  • Open a streamer to view their recordings and edit their site association.
  • Fetch missing streamer info (if supported for the selected site).
Sites
The Sites page shows an overview (recordings count, models count) and provides quick navigation to recordings or streamers filtered by that site.
Tags
Tags are your main way to group and filter recordings across different sites/streamers.
  • Create tags on the Tags page, or assign them from the Recordings view.
  • Rename or delete tags (deleting removes the tag from all recordings).
  • Open a tag to browse recordings filtered by that tag.
Data safety notes
  • Delete actions remove files from disk. Use with care.
  • Move/Copy can target any folder. Moving outside the catalog removes those items from the catalog.
  • Camero stores its catalog database and generated assets under .camero/ inside the catalog root.
Troubleshooting
  • "Catalog root is not configured": open Settings and set the catalog folder path.
  • Wrong streamer/site/date: adjust the filename regex and use Rescan metadata, or edit metadata from the recording modal.
  • Video won’t play in the browser: use Make playable (remux MP4) (especially for MKV/AVI/TS).
  • No thumbnails/avatars: set them from the recording modal using the current player frame.
  • FFmpeg warning banner: Camero requires FFmpeg/FFprobe. Install FFmpeg and add it to PATH (or place the executables next to the app), then click Retry.
