# Copy site logos here

Site logos are not distributed with this repository for intellectual property
reasons. After cloning, copy any logos you are authorized to use into this folder
on your own computer. Git ignores these local files.

Use PNG images named after the site: convert the site name to lowercase and
remove everything except letters a-z and digits 0-9.

Examples:

- `Amateur.TV` -> `amateurtv.png`
- `Chaturbate` -> `chaturbate.png`
- `MyFreeCams` -> `myfreecams.png`

Without a local PNG logo, Camero uses its generated fallback logo.
